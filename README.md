# Bizconnect Commerce

Responsive website for TikTok Shop, eBay and Etsy account-management services.

## Structure

- `index.html` — website content and semantic structure
- `styles.css` — responsive design system
- `script.js` — navigation, animations and MC011 upload experience
- `.nojekyll` — GitHub Pages configuration

## MC011

The MC011 form currently validates video files and saves a feedback draft in the visitor's browser. Connect the submit handler to authenticated cloud storage and a database before accepting real customer uploads.

## Deployment

The project is ready for GitHub Pages. Add a custom domain after its DNS records are configured.
